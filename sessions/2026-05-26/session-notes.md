## 学习内容

### 知识点 1: 专利权侵权与责任承担

**学生初始理解**:
- 能抓住“未经许可”“生产经营目的”“生产、销售专利产品”三个关键词。
- 能判断乙公司侵犯甲公司的专利权，并写出停止侵害、赔偿损失。

**讲解内容**:
- 专利权依法申请并授权后产生。
- 未经专利权人许可，为生产经营目的制造、使用、销售等实施专利的行为，可能构成专利权侵权。
- 权利人可依法要求停止侵害、赔偿损失等。

**理解检查**:
- 问题：乙公司未经许可，为销售目的生产、销售甲公司已取得发明专利的智能台灯，侵犯什么权利？承担哪些责任？
- 学生回答：乙公司未经许可，为生产经营目的生产、销售甲公司的专利产品，侵犯了甲公司的专利权。甲公司可以要求乙公司停止侵害，赔偿损失。
- 结果：✅ 正确，仅有“专利权权”笔误。

**掌握程度**: 🟢 已掌握

### 知识点 2: 诉讼权利

**学生初始理解**:
- 能直接识别回避、上诉、刑事案件委托辩护等关键词。

**讲解内容**:
- 当事人有委托诉讼代理人或辩护人的权利：民事、行政诉讼中通常说委托诉讼代理人；刑事案件中犯罪嫌疑人、被告人有权委托辩护人。
- 当审判人员等与案件有利害关系，可能影响公正审理时，当事人可以申请回避。
- 不服一审裁判的，可以在法定期限内上诉，启动二审程序。

**理解检查**:
- 问题1：审判员是商家老板近亲属，小张可以行使什么权利？
- 学生回答：回避。
- 结果：✅ 正确。
- 问题2：刑事案件中，小李想请律师帮助辩护，体现什么权利？
- 学生回答：刑事案件中，犯罪嫌疑人或被告人有权委托辩护。
- 结果：✅ 正确，补充规范表述为“委托辩护人”。
- 问题3：不服一审判决可以行使什么权利？
- 学生回答：上诉权。
- 结果：✅ 正确。

**掌握程度**: 🟢 已掌握

### 知识点 3: 诉讼程序

**学生初始理解**:
- 能记住完整程序链条。

**讲解内容**:
- 民事诉讼通常经历起诉、立案、应诉、开庭审理、判决/裁定、上诉或生效执行等环节。
- 材料题要能把具体行为对应到程序名称：提交诉状是起诉，法院受理是立案，提交答辩状是应诉，到庭围绕证据和争议焦点审理是开庭审理。

**理解检查**:
- 问题：小陈提交诉状、法院受理、商家提交答辩状、双方到庭审理分别是什么程序？
- 学生回答：起诉 → 立案 → 应诉 → 开庭审理 → 判决/裁定 → 上诉或生效执行。
- 结果：✅ 正确。

**掌握程度**: 🟢 已掌握

### 知识点 4: 证据意识与证据作用

**学生初始理解**:
- 能说出网购维权应保存订单页面、聊天记录、付款记录、开箱视频、检测报告等材料。

**讲解内容**:
- 诉讼中要以事实为根据，但事实需要通过证据证明。
- 当事人应有证据意识，依法收集、保存和提交证据。
- 常见证据包括书证、物证、视听资料、电子数据、证人证言、当事人陈述、鉴定意见、勘验笔录等。
- 侵权或消费纠纷中，证据不仅要证明“买过”，还要证明商品问题、损害结果、因果关系和诉讼请求依据。

**理解检查**:
- 问题1：网购手机发现假货，只凭感觉没有保存证据，问题在哪里？应收集什么？
- 学生回答：没有收集证据，订单页面聊天记录付款记录开箱视频检测报告等材料。
- 结果：✅ 正确。
- 问题2：健身房退费纠纷中，委托律师、申请回避、保存合同付款记录等分别体现什么？
- 学生回答：诉讼代理权、回避、收集证据的意识、证明的作用。
- 结果：✅ 基本正确，规范表述应为“委托诉讼代理人的权利”。
- 问题3：培训机构“保证提分30分”纠纷中，不同证据分别能证明什么？
- 学生回答：招生海报截图能证明机构是否宣传保证提分30分，聊天记录能证明客服是否承诺，付款记录能证明已支付培训费用，课程合同能证明双方存在合同关系。
- 结果：✅ 正确。
- 问题4：护肤品过敏纠纷中，只有付款记录会遇到什么困难？应补充什么？
- 学生回答：没有充分的证据，商品包装、聊天记录、就医记录、检测报告。
- 结果：✅ 正确，需补充“证明商品问题、损害结果和因果关系”。

**掌握程度**: 🟢 已掌握，表达完整性 🟡 需继续巩固

### 知识点 5: 综合材料中的消费者权利、诉讼权利与证据

**学生初始理解**:
- 能从“原装正品但实际是假货”中判断侵犯知情权。
- 能判断保存材料体现证据意识，不服一审可上诉，有利害关系可申请回避。

**讲解内容**:
- 假冒“原装正品”会侵犯消费者知情权，也可能侵犯公平交易权。
- 证据作用要具体写：订单和付款记录证明交易事实，客服承诺和宣传页面证明商家承诺，开箱视频和照片证明商品状况，综合支持退货退款和赔偿请求。
- 不服一审判决可在法定期限内行使上诉权；审判员与商家有利害关系，可申请回避。

**理解检查**:
- 问题：假冒正品耳机纠纷中，商家侵犯哪些消费者权利？证据有什么作用？不服一审和审判员有利害关系时分别行使什么权利？
- 学生回答：知情权；收集证据意识，可以证明商家是否采用假冒商品；上诉权；回避。
- 结果：✅ 核心判断正确，🟡 需补充公平交易权和证据具体证明内容。

**掌握程度**: 🟡 基本理解

### 答题技巧/记忆口诀
- 审判人员与案件有亲属或利害关系：申请回避。
- 不服一审裁判：法定期限内上诉。
- 民事/行政：委托诉讼代理人；刑事被追诉一方：委托辩护人。
- 程序链条：起诉 → 立案 → 应诉 → 开庭审理 → 判决/裁定 → 上诉或生效执行。
- 证据题：先写“证据意识”，再写“证明什么事实、支持什么请求”。

### 易错点记录
- “诉讼代理权”应改为“委托诉讼代理人的权利”。
- 假冒正品材料不要只写“知情权”，还可补“公平交易权”。
- 证据作用不能只写“证明是假货”，应具体拆成交易事实、宣传承诺、商品状况、损害结果、因果关系等。
